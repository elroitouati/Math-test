# מבחן במתמטיקה 📚

אפליקציית אנדרואיד שמלווה אותי עד המבחן במתמטיקה (ט׳ קבוצה א׳ מואצת) – **יום ג׳, ל׳ חשון · 10/11**.

## מה יש בה
- **היום** – ספירה לאחור, אחוז התקדמות, המשימות של היום עם סימון ✓, משימות להשלמה מימים קודמים, ותצוגה של מחר.
- **תוכנית** – 8 ימי לימוד (שבת מנוחה) שמכסים את כל דפי החזרה והעמודים בארכימדס.
- **חומר** – נוסחאות הכפל המקוצר, שיטות פירוק, משוואות, שברים אלגבריים, משולש שווה שוקיים, דלתון, מערכת צירים ורשימת בדיקה למבחן.
- **התקדמות** – רצף ימים, מפת עקביות יומית והתקדמות לפי נושא.
- **התראות** – תזכורת יומית בשעה שבוחרים, תזכורת ערב רק אם נשארו משימות, בלי התראות בשבת.

## התקנה
מורידים את `release/math-exam-prep.apk` לטלפון ומתקינים (צריך לאשר "התקנה ממקורות לא ידועים").

## פיתוח
הקוד נמצא ב-`www/` (HTML/CSS/JS), עטוף ב-Capacitor.
```
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```
כל push בונה APK אוטומטית ב-GitHub Actions.
